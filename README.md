# SSMarket

Скрипт Tampermonkey: сортирует выдачу Ozon по числу отзывов и Wildberries по числу оценок.

## Что делает

- Сортирует только основную выдачу. Полки "Вы смотрели" и "Возможно, вам понравится" не трогает.
- Карточки остаются такими же, как на сайте: размер, ссылки, "в избранное", корзина.
- "Подгрузить ещё и отсортировать": листает выдачу 3, 5, 10 или N секунд, потом сортирует.
- "Как было" возвращает порядок сайта.
- Смена фильтра или сортировки сайта сбрасывает сортировку; с включённым "Держать сортировку при смене
  фильтров" новая выдача сортируется сама.
- Кнопку можно перетащить в любое место; место помнится отдельно для Ozon и для WB.

## Установка

1. Скопируй скрипт: `pbcopy < ~/Dev/ssmarket/ssmarket.user.js`.
2. Tampermonkey - "Панель управления" - открой SSMarket (1.0) на редактирование.
3. Выдели всё, вставь, сохрани (`⌘S`). Имя и пространство имён те же, поэтому это обновление 1.0, а не второй скрипт.
4. SSOzon и SSWildberries, если стоят, выключи: они рисуют свои кнопки.

## Как устроено

| Сайт | Как сортирует | Почему |
|---|---|---|
| Ozon | Снимает копии карточек основной выдачи, пока они видны, и рисует отсортированную сетку с классами сайта вместо выдачи | Выдача Ozon виртуальная: страницы вдали от экрана выгружаются. Кнопки в копиях (избранное, корзина) нажимают настоящую карточку |
| WB | Переставляет живые карточки CSS-свойством `order` | Все загруженные карточки лежат в одной сетке; DOM и React не трогаются |

Главная выдача Ozon - сетки `tileGridDesktop` внутри `infiniteVirtualPaginator` без заголовка; у полок есть
заголовок и flex-ряд. Карточка WB - элемент списка ровно с одним артикулом (рекламные карусели ссылаются на многие).
Число отзывов и оценок читается из отдельных текстовых узлов: в склеенном тексте рейтинг "4.6" прилипает к
"1 101 отзыв".

## Проверка

Тест - на живой выдаче в браузере-стенде (без окна, ru-выход):

```
AGENT_BROWSER_SESSION=ssm agent-browser --cdp 9225 eval "location.reload()"
test/inject.sh ssm 9225
```

`inject.sh` вставляет скрипт в открытую страницу так, как это сделал бы Tampermonkey, и собирает ошибки страницы в
`window.__ssmErrors`. Хранение места кнопки без Tampermonkey идёт в `localStorage`.

## Версии

Номер в `@version` и `VERSION` растёт с каждым выпуском (semver). Прежние скрипты - `legacy/`.
