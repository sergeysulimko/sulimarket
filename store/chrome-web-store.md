# Карточка в магазинах расширений

Тексты для Chrome Web Store (Chrome, Яндекс Браузер, Opera) и Edge Add-ons. Язык карточки - русский.
Пакет - `dist/sulimarket-<версия>-extension.zip` (`npm run build`), один и тот же для всех трёх магазинов.

## Подробное описание

Текст без разметки, вставляется как есть.

```
Ozon и Wildberries не умеют сортировать товары по количеству отзывов. SuliMarket добавляет эту сортировку: один клик - и наверху товары, которые купили и оценили тысячи людей, а не карточки с пятью звёздами от трёх покупателей.

Почему не рейтинг
Рейтинг не говорит, сколько людей его поставили. Товар с оценкой 5,0 от трёх покупателей стоит выше товара с 4,8 от 40 000 покупателей. SuliMarket ставит наверх товары с большим количеством отзывов (на Wildberries - оценок), а рейтинг учитывает при равенстве. Только на рейтинг смотрят 4% покупателей (Роскачество, 2025). Накрутить можно и количество отзывов, поэтому отзывы перед покупкой всё равно стоит читать.

Что умеет
- Сортирует только основную выдачу. Полки "Вы смотрели", "Возможно, вам понравится" и реклама не попадают в сортировку.
- Сохраняет вёрстку сайта: карточки того же размера, работают "В избранное", корзина и переход к товару.
- Листайте как обычно: после сортировки сайт догружает выдачу при прокрутке, новые товары встают под отсортированными.
- Не теряет новые товары: внизу окна появляется "Ещё N товаров без сортировки" и кнопка "Досортировать".
- Листает за вас: 3, 5, 10 секунд или своё число секунд прокрутки, потом сортирует всё загруженное.
- Помогает выбрать продавца на Ozon: в окне "Другие предложения" видно рейтинг, отзывы, заказы магазина и сколько он работает с Ozon, а кнопка "По отзывам" ставит наверх продавцов с большим числом отзывов на этот товар.
- "Как было" возвращает порядок сайта.
- "Держать": после смены фильтра, категории, поиска или возврата назад новая выдача сортируется сама.
- Кнопку можно перетащить в любое место экрана, место запоминается для каждого сайта.
- Для AI-агентов и автоматизации: адрес выдачи с ?sulimarket=10 сам листает и сортирует, результат - в JSON на странице.

Как пользоваться
1. Откройте поиск или категорию на ozon.ru или wildberries.ru.
2. Нажмите круглую кнопку SuliMarket в правом нижнем углу.
3. Нажмите "Сортировать по отзывам" или выберите 3 с, 5 с, 10 с, чтобы сначала догрузить больше товаров.

Приватность
SuliMarket работает только на www.ozon.ru и www.wildberries.ru. Он не собирает и не передаёт данные: нет сервера, аналитики, рекламы и запросов к другим сайтам. Сведения о магазинах в окне продавцов он берёт у самого Ozon. Хранятся только настройки в вашем браузере.

Работает в Google Chrome, Яндекс Браузере, Microsoft Edge и Opera.

Бесплатно, без рекламы, код открыт: github.com/sergeysulimko/sulimarket
```

## Вкладка "Конфиденциальность" (Privacy practices)

**Единственное назначение (single purpose):**

```
Сортирует выдачу товаров на Ozon и Wildberries по количеству отзывов и оценок.
```

**Обоснование разрешений:**

| Разрешение | Текст |
| --- | --- |
| `storage` | Хранит настройки пользователя: место кнопки на экране, выбранное время прокрутки и переключатель "Держать сортировку". |
| Доступ к сайтам (`https://www.ozon.ru/*`, `https://www.wildberries.ru/*`) | Расширение читает карточки товаров на странице выдачи, чтобы узнать число отзывов, и переставляет карточки по этому числу. На других сайтах не работает. |

**Удалённый код:** нет. Весь код в пакете.

**Сбор данных:** ничего не отмечать - расширение не собирает ни одной категории данных.

**Подтверждения:** отметить все три - данные не продаются третьим лицам, не используются вне назначения, не
используются для кредитных решений.

## Firefox

Не готово: для addons.mozilla.org нужна своя сборка (`browser_specific_settings.gecko`, декларация сбора данных) и
проверка в Firefox. Пользователи Firefox пока ставят скрипт через Tampermonkey.
