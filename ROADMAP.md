# ROADMAP

Что планируется в SuliMarket. Что уже вышло - в [CHANGELOG.md](CHANGELOG.md).

## Магазины

- [ ] Chrome Web Store.
- [ ] Edge Add-ons, Opera Add-ons - тот же пакет.
- [ ] Firefox (addons.mozilla.org): своя сборка с `browser_specific_settings.gecko`.

## Функции

- [ ] Другие маркетплейсы: Яндекс Маркет, AliExpress, Avito, Мегамаркет.
- [ ] Выбор ключа сортировки: отзывы, рейтинг при пороге отзывов, цена за отзыв.
- [ ] Горячая клавиша сортировки.
- [ ] Мобильная вёрстка Ozon и Wildberries (сейчас только версия для компьютера).
- [ ] Команда и MCP-сервер для агентов: "топ-N товаров по запросу X на Ozon/WB по числу отзывов".

Идеи и ошибки - в [issues](https://github.com/sergeysulimko/sulimarket/issues/new/choose).
