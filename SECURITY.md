# Безопасность

SuliMarket не отправляет данные ни нам, ни третьим лицам и не хранит их вне вашего браузера. Запросы он делает только
к самим Ozon и Wildberries - за сведениями о продавцах (см. [PRIVACY.md](PRIVACY.md)).

Нашли уязвимость - напишите через [GitHub Security Advisories](https://github.com/sergeysulimko/sulimarket/security/advisories/new),
а не в открытый issue. Отвечу в течение недели.

Поддерживается последняя версия.
